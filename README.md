# 🛒 电商运营分析项目 | 天池数据集实战
> 基于阿里云天池公开数据集的电商全链路数据分析项目，完整覆盖**数据仓库建模 → 业务指标分析 → PowerBI可视化看板**全流程，沉淀了电商经营、用户运营、商品运营三大核心场景的分析方法与实践经验。

---

## 📌 项目概述
本项目以阿里云天池公开电商运营数据为数据源，通过 MySQL 构建了完整的数仓分层架构（ODS/DWD/DWS/ADS），完成了从原始数据清洗到业务指标建模的全流程处理，并使用 PowerBI 开发了可视化看板，实现了电商核心经营指标、用户分层运营、商品销售表现的多维度分析，为电商业务决策提供数据支撑。

### ✨ 项目亮点
- **完整数仓架构设计**：严格遵循 ODS→DWD→DWS→ADS 分层建模规范，实现数据的标准化、可复用管理
- **核心业务建模沉淀**：完成用户 RFM 分层模型、商品 ABC 分类模型等电商经典分析方法的落地实现
- **全场景可视化看板**：覆盖经营总览、用户运营、商品运营三大模块，直观呈现业务现状与趋势
- **数据驱动业务落地**：基于分析结果输出业务洞察与优化建议，将数据价值转化为可执行的运营策略

## 🗂️ 数据仓库架构设计
本项目采用经典的四层数仓架构，实现数据从原始到业务可用的全链路处理：

| 分层 | 说明 | 核心内容 |
|------|------|----------|
| **ODS层（原始数据层）** | 直接同步天池原始数据集，保留数据原貌 | 用户行为表、订单表、商品表、支付表等原始数据，仅做数据格式校验与分区 |
| **DWD层（明细数据层）** | 数据清洗与标准化，构建业务明细宽表 | 清洗脏数据、处理缺失值、统一数据口径，构建用户行为宽表、订单明细宽表 |
| **DWS层（汇总数据层）** | 按业务主题进行轻度聚合，生成中间指标 | 按时间、用户、商品维度聚合生成日/周/月粒度的订单汇总、用户行为汇总、商品销售汇总表 |
| **ADS层（应用数据层）** | 面向分析场景的最终指标建模 | 实现 RFM 用户分层、商品 ABC 分类、复购率/转化率等核心业务指标的计算与结果输出 |

## 📊 核心建模与分析方法
### 1. 用户分析建模
- **RFM 用户分层模型**：基于用户最近消费时间（Recency）、消费频率（Frequency）、消费金额（Monetary）三个维度，将用户划分为高价值核心用户、高潜大额新用户、沉睡大额低频用户等5类，支撑精细化运营策略制定
- **用户复购分析**：追踪首单用户与复购用户的趋势变化，计算整体复购率，定位用户留存薄弱环节
- **用户行为转化分析**：从浏览-加购-收藏-下单-支付全链路拆解转化漏斗，识别转化瓶颈

### 2. 商品分析建模
- **商品 ABC 分类模型**：基于商品销售额贡献度，将商品划分为A（高贡献核心商品）、B（中贡献潜力商品）、C（低贡献长尾商品）三类，实现资源倾斜与库存优化
- **品类转化分析**：对比不同品类的用户行为转化差异，定位高转化优势品类与低转化待优化品类
- **价格带分布分析**：分析不同价格带商品的销售贡献，识别用户价格偏好与主力价格区间

### 3. 经营指标分析
- 核心经营指标监控：GMV、订单量、消费用户数、单均价、复购率等关键指标的趋势追踪
- 时间维度分析：月度趋势、周度销售分布分析，识别业务波动规律与销售高峰时段

## 📈 PowerBI 可视化看板展示
项目开发了三大核心看板，全面覆盖电商运营核心场景：

### 1. 电商经营分析总览看板
- 核心指标卡片：GMV、订单量、消费用户数、单均价、复购率
- 趋势分析：GMV与订单趋势、单均价趋势、周度销售分布
- 用户质量分析：复购用户vs首单用户趋势对比

### 2. 用户运营看板
- 流量与转化指标：UV、PV、消费用户数、复购用户数、复购率
- 用户行为漏斗：PV/UV全链路转化分析
- 用户分层变化：不同层级用户的规模与占比趋势
- RFM用户分层结果：各层级用户GMV贡献与占比分布

### 3. 商品运营看板
- 商品核心指标：商品销售额、总销量、曝光量、总转化率、爆品率
- 商品销售TOP榜：Top20热销商品排名
- 品类转化对比：不同品类的全链路转化差异
- 价格带与ABC分类分析：价格带销售分布、ABC分类商品贡献度
